# ⚡ 雷霆 DeepSeek 微信自动回复脚本

> 用 DeepSeek 大模型驱动你的微信 PC 端：**模仿你自己的说话风格**自动回复好友，
> 支持图片识别、表情包、人格学习、熔断保护、让位机制，并带一个漂亮的命令行控制台。

作者：**南风知我意**

---

## ✨ 功能一览

| 功能 | 说明 |
|---|---|
| 🧠 **人格学习** | 读取你的历史聊天记录，用 AI 提炼出你的说话风格，回复像你本人 |
| 💬 **上下文记忆** | 每个会话独立记忆，重启不丢，能接着话题聊 |
| 🖼 **图片识别** | 好友发图自动下载解密，交给视觉模型看懂再回复 |
| 😂 **表情包** | 看懂对方发的表情包，也能用自己的表情包回击 |
| 🛡 **熔断保护** | 防止被恶意刷 token：频率限制 + 每日额度 |
| 🙋 **让位机制** | 你亲自打字时，机器人自动闭嘴，绝不抢话 |
| 🎛 **遥控开关** | 在微信「文件传输助手」发指令即可暂停/恢复/静音某人 |
| 🖥 **控制台** | 命令行直接开关，带**自动纠错**（打错字也能认出来） |
| 🛠 **工作模式** | 对方说"帮我做个 XX 文件"→ **按要求的格式真做出来，把文件发回给他**<br>支持 **Word(.docx) / Excel(.xlsx) / PPT(.pptx) / PDF / HTML / Markdown / Python / JSON / CSV** 等 |
| 🎬 **PPT 美化** | **4 套配色轮换**（深蓝/深紫/墨绿/深棕）+ **3 种版式**（要点/大数字/金句）+ 平滑切换与逐条淡入动画，默认 15~22 页 |
| 📤 **发文件** | 做好的文件直接发回给对方（微信 4.x 走「文件夹→选择文件」路线，自动最大化窗口 + 数据库校验，绝不假报成功） |
| 🔒 **隐私红线** | 绝不向别人泄露你的真名、住址、聊天记录等隐私 |

## 🚀 快速开始

### 第一步：安装

双击 **`install.bat`**，脚本会自动：

1. 检查 Python（需要 3.11 或更高版本）
2. 在 `%USERPROFILE%\AppData\Local\wechatbot\venv` 创建独立虚拟环境
3. 安装依赖（用华为云镜像，国内速度快）
4. 生成配置文件 `.env`

> 没装 Python？去 <https://www.python.org/downloads/> 下载安装，
> **务必勾选 "Add Python to PATH"**。

### 第二步：填 API Key

双击 **`编辑配置.bat`**（或直接用记事本打开 `.env`），填入你的 DeepSeek Key：

```ini
DEEPSEEK_API_KEY=sk-你的key
```

Key 在 <https://platform.deepseek.com/api_keys> 免费申请（需充值少量余额）。

### 第三步：启动

1. 登录 **微信 PC 版（4.1.15.x）**，窗口**不要最小化、不要锁屏**
2. 双击 **`run.bat`**

看到欢迎横幅就说明成功了：

```
════════════════════════════════════════════════════════════
   欢迎使用由【南风知我意】制作的
   ⚡ 雷霆DeepSeek微信自动回复脚本 ⚡
   人格模仿 · 图片识别 · 表情包 · 熔断保护 · 让位机制
```

## 🖥 控制台命令

启动后，在**同一个黑窗口**直接输入命令，回车执行：

| 命令 | 作用 |
|---|---|
| `on` / `开启` | 恢复自动回复 |
| `off` / `关闭` | 暂停自动回复（谁都不回） |
| `group off` | 群聊：完全不回 |
| `group mention` | 群聊：只回 @我 的 |
| `group all` | 群聊：全都回（慎用） |
| `work on` / `work off` | **工作模式**开关：要文件就真做出来发给他 |
| `status` / `状态` | 查看状态和今日用量 |
| `mute 昵称` | 静音某个人 |
| `unmute 昵称` | 解除静音 |
| `help` / `?` | 显示全部命令 |
| `quit` / `退出` | 关闭脚本 |

**防呆设计**：打错字、多打标点、用全角字母都能自动纠正。

```
雷霆> 暂停吧
🔧 没看懂「暂停吧」，自动按「暂停」处理
⏸ 已暂停自动回复（输入 on 恢复）
```

## 📱 微信遥控

在微信里打开 **「文件传输助手」**，发这些指令给"自己"：

| 发送 | 效果 |
|---|---|
| `暂停` / `关了` | 全局暂停 |
| `开启` | 恢复 |
| `状态` | 查看状态和用量 |
| `群聊 关闭` / `群聊 @我` / `群聊 全部` | 切换群聊策略 |
| `静音 张三` | 静音某人 |
| `取消静音 张三` | 解除 |

## ⚙️ 配置说明（`.env`）

```ini
# ---- 必填 ----
DEEPSEEK_API_KEY=sk-xxxx          # 你的 DeepSeek Key
AUTHOR_NAME=南风知我意             # 横幅署名

# ---- 人格与记忆 ----
ENABLE_STYLE_LEARNING=1           # 首次启动自动学习你的说话风格
STYLE_SAMPLE_MAX=400              # 学习时采集多少条历史发言

# ---- 群聊 ----
REPLY_GROUPS=off                  # off / mention / all

# ---- 回复格式 ----
REPLY_FORMAT=auto                 # auto=短句拆条、代码整段；split=总是拆条；merge=合成一句

# ---- 图片 / 表情包 ----
ENABLE_IMAGE=1
ENABLE_STICKER=1
DEEPSEEK_VISION_MODEL=deepseek-flash

# ---- 熔断保护 ----
BREAK_MAX_MSGS_PER_MIN=8          # 每分钟最多回几条（超了只等待，不熔断）
BREAK_MAX_TOKENS_PER_CHAT=150000  # 单会话每日 token 上限
BREAK_MAX_TOKENS_TOTAL=1000000    # 全局每日 token 上限

# ---- 让位 / 白名单 ----
YIELD_MINUTES=3                   # 你手打过字的会话，几分钟内不插嘴
WHITELIST=filehelper,文件传输助手  # 白名单：不熔断、跳过隐私过滤、可自问自答
SKIP_BACKLOG=1                    # 启动只回新消息，不补停机期间的积压

# ---- 隐私 ----
PRIVACY_NAMES=                    # 你的真名等，注入提示词前会被替换掉
```

## ❓ 常见问题

| 现象 | 解决 |
|---|---|
| `未检测到 Weixin.exe` | 微信没登录 / 没启动 / 被最小化 |
| 能收消息但不回复 | 私聊都会回；群聊默认关闭；检查是否被熔断 |
| 回复不像我 | 删掉 `persona.txt` 重启，会重新学习 |
| 机器人抢话 | 让位机制没生效？确认 `YIELD_MINUTES>0` |
| 想立刻停 | 控制台输入 `off`，或微信发「暂停」 |
| 图片不识别 | 自动下载大图需要微信窗口可见、不锁屏 |
| pip 安装失败 | 脚本会自动重试官方源；也可手动 `pip install -r requirements.txt` |

## ⚠️ 重要提醒

1. **封号风险**：任何微信自动化工具都有风险，**建议用小号测试**，别拿主号冒险。
2. **隐私安全**：`.env`、`persona.txt`、`chat_history.json` 都是你的私人数据，
   **不要上传到 GitHub**（`.gitignore` 已经帮你排除）。
3. **仅供学习交流**，请遵守微信用户协议与当地法律法规，使用后果自负。
